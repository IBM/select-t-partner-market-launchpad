# Lab 101 - Core MREF - Lab Guide

## Introduction

Welcome to the Core MREF (Maximo Reference Data) lab. In this hands-on session, you'll explore the foundational reference data structures that support all Maximo Application Suite modules.

## Prerequisites

- Access to IBM Maximo Application Suite environment
- Basic understanding of asset management concepts
- Completion of Core Manage lab (recommended)

## Lab Objectives

By the end of this lab, you will be able to:

- Navigate and understand Maximo Reference Data structures
- Work with classification systems and hierarchies
- Configure and manage domain values
- Understand how master data supports asset management operations
- Apply reference data to assets and work orders
